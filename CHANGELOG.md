# История версий

## 1.1.1 — 19.11.2026

- Локальные сборки могут запускаться с Groq по умолчанию через переменную окружения.

## 1.1.0 — 19.11.2026

- Генерация миров учитывает исходную гипотезу. Ответы модели проверяются перед сохранением.
- Image-модель рисует локации и портреты по запросу, сцены и финалы можно озвучить.
- Жители ведут три сюжетные линии в автономном дневнике. Во время исследования находятся артефакты.
- Бог может вдохновить конкретного жителя, защитить место оберегом или раскрыть тайник.
- Развилки создают отдельные записи в архиве. Ответы модели и жителей обновляют свою ветвь.
- Добавлены проверки движка, API иллюстраций и игрового сценария в браузере.

## 1.0.0 — 14.11.2026

Релиз для конкурса «Креативное поколение».

**Игра**
- создание вселенной из одной гипотезы: мир через 60 лет, 5 законов, 5 локаций, 3 жителя;
- шесть точек выбора по три пути, метрики (порядок, воля, доверие, технологии), пять финалов;
- союзники: житель с доверием 50 %+ усиливает решение;
- исследование локаций: сцены, сдвиг метрик, запись в хронику;
- ветви: возврат к любой точке и пересчёт последствий;
- роль игрока и цель партии, проверяется в финале.

**Бог вселенной**
- вкладка «Бог»: знамения, милость и кара, вера;
- журнал бога с исходами;
- сфера бога на экране мира;
- дневник мира: две записи после каждого решения, дрейф метрик.

**AI CORE**
- провайдеры: демо-движок, Gemini, Groq, OpenRouter, DeepSeek, Ollama, свой сервер;
- пресеты моделей (Groq, OpenRouter);
- фолбэк на локальный движок при ошибке сети или ключа;
- обложки миров и генеративная графика.

**Дизайн**
- тёмная космическая палитра, Unbounded + Manrope;
- крупные размеры текста и просторные строки;
- анимации сборки мира, пульсирующая сфера бога;
- озвучка вступления системным синтезом речи;
- онбординг из трёх экранов.

**Технически**
- Expo SDK 58, React Native 0.88, TypeScript strict;
- офлайн-хранение архива миров (AsyncStorage);
- APK для Android 7+, подпись debug;
- презентация проекта: `PARALLEL-презентация.pptx` / `.pdf`.
